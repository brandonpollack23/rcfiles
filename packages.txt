# Everything `mise run deps` installs, on every OS, in groups. `core` goes on
# every machine and `mac` on every Mac; deps asks which of the others to
# install and remembers the answer (`mise run deps <group>...` to change it).
#
# One package per line: <name> [option]... # what it is
# By default <name> comes from Homebrew (the Mac, Debian and Fedora) and from
# pacman or the AUR (Arch, through yay or paru). Options:
#   arch=<pkg>[,<pkg>]  its name(s) on Arch; arch=- to skip it there
#   brew=<formula>      its Homebrew formula, if not <name>; brew=- to skip it
#   cask[=<cask>]       a Homebrew cask instead (Mac only)
#   mas=<id>            a Mac App Store app instead (Mac only; sign in first)
#   cargo[=<crate>]     a Rust crate, installed with cargo binstall everywhere
# Formulae from other taps are named <user>/<tap>/<formula>; brew taps them.
# mise itself comes from install.sh.
